# 0.1.3 — 2026-08-22

## Added

- **Supply-chain and repository metadata** now include Bun's Socket install scanner, a three-day hold for third-party releases, normalized Git attributes, and GitHub community-health files.

## Changed

- **Current MCP SDK and protocol support** arrives through `@cyanheads/mcp-ts-core` `^0.10.9` → `^0.12.3`; tool inputs now reject undeclared root keys, and advertised output schemas accept the framework's structured error envelope.
- **`evals_submit_draft` confirmation** uses multi-round input on supported current and legacy transports; declined, cancelled, false, or invalid confirmations return the typed `submit_declined` failure without re-prompting.
- **`llm_rubric` records** rely on recorded independent verification and report `server_verified: false`; the removed sampling path is no longer described or attempted.
- **Bun and packaging** move to Bun 1.4.0, current Docker install flags, portable MCPB cleanup, and TypeScript typechecking across both source and tests.

## Fixed

- **Cross-field task and grader failures** now use `ValidationError` domain envelopes instead of `InvalidParams`, preserving structured reasons for client recovery.
