# 0.1.6 — 2026-10-13

## Changed

- **`evals_list_records.limit`** accepts positive safe integers above 500, honoring the requested limit with truncation disclosure.
- **Framework guidance and runtime** sync to mcp-ts-core 0.13.15 and Bun 1.4.3, including Docker base images.

## Fixed

- **Numeric grading** rejects unit-bearing candidates such as `5 kg` and non-real candidates such as `2+3i`; equivalent targets return `grader_unexecutable`. Finite real Number, BigNumber, Fraction, and zero-imaginary Complex results remain supported. ([#5](https://github.com/cyanheads/evals-mcp-server/issues/5))
- **Draft persistence** checks grader executability before create or revise writes, preventing orphan creates and preserving draft bytes after a failed revision. Executable failing-gold drafts remain editable. ([#6](https://github.com/cyanheads/evals-mcp-server/issues/6))
- **Surgical patches** reject unknown typed paths such as `not.real` and `metadata.typo` atomically. Declared optional fields, arbitrary JSON object paths, and grader-kind transitions remain supported. ([#9](https://github.com/cyanheads/evals-mcp-server/issues/9))
- **Frozen discard** returns `record_frozen` with ValidationError (-32007), matching its declared contract. ([#10](https://github.com/cyanheads/evals-mcp-server/issues/10))
- **Submit gate dispatch** uses exhaustive literal failure reasons so error-contract lint covers the handler, preserving refusal messages, data, codes, and recovery. ([#11](https://github.com/cyanheads/evals-mcp-server/issues/11))
- **Create text output** includes the complete normalized record JSON alongside review and self-consistency sections. ([#15](https://github.com/cyanheads/evals-mcp-server/issues/15))
