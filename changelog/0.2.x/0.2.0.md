# 0.2.0 — 2026-11-13

## Added

- Add the evals-guide skill and serve it at `skill://evals-guide/SKILL.md`. The guide ships with plugin, npm, Docker, and MCPB installs.
- **`evals_list_records`** adds `offset` and `nextOffset` with stable ordering for an unchanged corpus. Resource discovery lists every valid record ([#27](https://github.com/cyanheads/evals-mcp-server/issues/27)).
- **String normalization** adds `remove_punct` and opt-in set element normalization and comma or newline delimiters ([#23](https://github.com/cyanheads/evals-mcp-server/issues/23)).

## Changed

- **Numeric and rubric bounds** reject negative tolerances even when paired with a nonnegative tolerance that previously yielded correct verdicts. Rubrics require a threshold in [0, 1], nonnegative weights, and a positive effective weight on at least one criterion ([#24](https://github.com/cyanheads/evals-mcp-server/issues/24)).
- **Inspect export** emits a sample array in place of `{version,format,samples}`. Context prefixes `input`, structured gold becomes JSON text in `target`, and multiple-choice targets use A–Z followed by 1, 2, and so on ([#25](https://github.com/cyanheads/evals-mcp-server/issues/25)).
- **lm-eval export** includes context and omits unsupported metric hints. Both harness formats retain `grader_spec` for downstream scoring ([#25](https://github.com/cyanheads/evals-mcp-server/issues/25)).

## Fixed

- **Readiness and submit** share local checks. Failed positives and failed or disagreeing evidence block submission, and rubric drafts require a negative case and label skipped verdicts as ungraded ([#18](https://github.com/cyanheads/evals-mcp-server/issues/18), [#19](https://github.com/cyanheads/evals-mcp-server/issues/19)).
- **Reviewer prompts** give the problem, context, and choices before asking the reviewer to fetch saved gold.
- **Stored records** are validated on reads. Direct failures identify the invalid record, and scans report skipped files while processing valid records. JSONL remains lossless, including validated stored extension fields ([#21](https://github.com/cyanheads/evals-mcp-server/issues/21)).
- **`json_match`** honors explicit draft-07, 2019-09, and 2020-12 declarations and reports ignored keywords in grade details. It rejects asynchronous schemas before grading to prevent unhandled validation failures ([#22](https://github.com/cyanheads/evals-mcp-server/issues/22)).
- **JSON equality and content hashing** retain literal property names such as `__proto__` without rewriting stored hashes.
- **`strip_latex`** preserves balanced inner groups when removing presentation wrappers ([#23](https://github.com/cyanheads/evals-mcp-server/issues/23)).
- **`captured_outputs`** is server-owned and rebuilt from captures resolved for each submission ([#28](https://github.com/cyanheads/evals-mcp-server/issues/28)).

## Security

- **Record paths** accept only server-generated IDs, preventing caller-supplied IDs from reaching files outside the record store ([#20](https://github.com/cyanheads/evals-mcp-server/issues/20)).
